# Hack-a-Course: Friday Mini-Hack

---

## Summary
This fast-paced "Mini-Hack Friday" aims to let students build custom AI tools for studying. We move beyond the limitations of Brightspace by creating personalized assistants that streamline the learning process without replacing the intellectual effort of studying. Especially creativity will be rewarded - students can come up with any kind of tool!

*   **Event Window:** Friday Afternoon (13:00 – 17:00)
*   **Timing:**
    *   **Option A:** Some weeks before exams (High motivation for tool-building)
    *   **Option B:** A Friday short after exams (High energy, celebratory atmosphere)

---

## The Challenge: "Beyond Brightspace"
While Brightspace serves as info center, we often find it cumbersome to navigate folder structures and different course set-ups to find specific information. This hackathon challenges students to build a **Personal Study Guide** using a provided dataset of course files (PDFs) from a random course.

---

## Creative Tool Examples
Participants are encouraged to think outside the box. Examples include:
*   **The Question Asker:** An AI that doesn't give answers, but asks guiding questions based on the course literature to lead the student to the solution.
*   **Visual Concept Mapper:** A tool that parses PDFs and generates a Mermaid.js or SVG knowledge graph to show how different lectures interlink.
*   **The "Jargon Buster":** A browser extension or sidebar that instantly explains course-specific acronyms and technical terms using the official course glossary.
*   **Contextual Citation Bot:** A tool where you type a statement, and it finds a possible page and paragraph in the reading list that supports or refutes it.

---

## Safety & Requirements
**Data Integrity & Security:**
*   **Zero-Trust Policy:** No university credentials are to be integrated into student projects.
*   **Local-First:** Students are encouraged to use local LLM frameworks (like Ollama) or provided temporary API sandbox keys.
*   **Safe Content:** All tools must include a system prompt ensuring the AI identifies itself as an assistant and refuses to generate direct answers for graded assignments.
