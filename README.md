# Hack-a-Course: Friday Mini-Hack

## Summary
I propose a short mini hackathon in which students must build a personalized AI agent for studying. This is motivated by the fact that Brightspace and provided course materials can be cumbersome to navigate within. 

---

* **Timing** Friday Afternoon (13:00-17:00)
* **Goal** Personalized Study Agent
* **Evaluation**
    *   Performed by either staff / us on the following topics:
    *   Usefulness (Would you consider it a useful tool?) (1-5)
    *   Complexity (1-5)
    *   Creativity (From the scale of a basic pick-the-date tool or did they go all the way?) (1-5)
    *   Robustness (1-5)
* **Provided** Course Files of some course
* **Requirements**
    *   Objective: the tool should make a student **better** at studying, not lazier =)
    *   Safety: no usage of UL passwords allowed - if we see that in your code the ... won't be considered
    *   Framework: you're not allowed to create tools which solve assignments for you - these won't be considered
* **PRIZES**
    *   First price: individual bol.com gift card (20eu pp)
    *   Second price: book about AI
    *   Third price: individual De Fusie after-study drink-voucher

---

* **LOGISTICS**
    *   We provide baseline code to parse the Course files into structured format (Python) and an UI with basic 'toolkit' connection
    *   Pizzas and a drink will be included
    *   (Entrance fee depends on whether the participant wants pizza or not)
    *   COSTS:
    *   prizes: 20*4 + 15 * 4 + 5 * 4 = 160 euro
    *   pizzas + drinks = 15 + 5 = 20 euro per participant

Students can team up with 3-4 people.
